PRODUCT

The Trade Flow:
Plan → Size → Execute


1. PLAN

Select instrument → Gate checklist activates. Manual gates require proof (justification or screenshot). Auto-gates compute live (session window, lock status, cap). Cannot proceed until ALL pass.

2. SIZE

Calculator auto-computes lot size from risk cap ($125 default). Validates R:R ≥ 1:2. Blocks oversized positions. Multi-entry stacking capped at combined risk limit.

3. EXECUTE

Final validation: lock status, session, daily cap. Trade logs → immediate 30-second reflection (plan adherence, exit type, emotional state 1-10). Data feeds Edge Map.


⚡ At any step, if a rule is violated → haptic vibration + red banner + blocked
