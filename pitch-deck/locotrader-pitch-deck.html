PRODUCT

The Trade Flow: Plan → Size → Execute

Every trade passes through a 3-step wizard. At any step, if a rule is violated → haptic vibration + red banner + blocked.

1. PLAN — Gate Checklist

Select instrument → gates activate. Manual gates require typed justification or chart screenshot. Auto-gates compute live (session windows, lock status, daily cap). Cannot proceed until ALL pass.

2. SIZE — Risk Calculator

Auto-computes lot size from risk cap. Validates R:R ≥ 1:2. Blocks oversized positions. Multi-entry stacking capped at combined risk limit. No mental math.

3. EXECUTE — Final Check + Reflection

Last validation: lock, session, cap. Trade logs → immediate 30-sec reflection (plan adherence, exit type, emotional state 1-10). Data feeds the Edge Map.
